# myaworks/tap

Homebrew tap for the tools [myaworks](https://github.com/myaworks) publishes.

```sh
brew install myaworks/tap/pdf-ocr
```

| Formula | What it is |
|---|---|
| [`pdf-ocr`](https://github.com/myaworks/PDFOCR) | Adds a searchable text layer to scanned PDFs, using macOS Vision. Needs macOS 26 or newer. |

The GUI app is not here — grab `PDFOCR.app` from
[the releases page](https://github.com/myaworks/PDFOCR/releases) instead.
